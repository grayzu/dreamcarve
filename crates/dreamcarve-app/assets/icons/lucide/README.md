# Lucide

The app's icon set (`docs/specs/phase-4/experience.md`, section 6), as
an icon font loaded as the egui font family `icons`.

- Source: https://github.com/lucide-icons/lucide, release
  [1.67.0](https://github.com/lucide-icons/lucide/releases/tag/1.67.0),
  archive `lucide-font-1.67.0.zip` (SHA-256
  `db8ed26ed8ec84d7251e2d9c0eb028358db59c3f4bab3532d65e2f4b17e60163`).
- Files: `lucide-font/lucide.ttf`, unmodified (SHA-256
  `23730b56d04bc009e9ecf6a0598ef9d82a3ba4ba055d4d9115976e4a385eff7e`), and
  `lucide-font/codepoints.json`, the name-to-code-point map that
  `src/widgets/icon.rs` is checked against. `LICENSE` is the repository's
  at the release tag.

  (`LICENSE` lists them). Listed in `NOTICE`.
